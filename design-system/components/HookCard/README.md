La carte Hook présente une alternative trouvée par Hooka : son nom, où elle est, ce qu'elle coûte, ce qu'on gagne et le bouton pour y aller.

**Ce que tu fournis** : le nom de l'alternative, le lieu avec sa distance et son temps, le prix (et le prix de référence barré), le gain en euros, une équivalence d'impact, et le lien vers la fiche de confiance.

- Affiche toujours trois Hooks, classés par budget, proximité, temps et impact. Le premier est une `hk-card` complète avec `hk-btn--primary` ; les suivants sont compacts, sans bouton principal.
- Le gain en euros est une pastille `hk-chip--blush`, l'équivalence d'impact une pastille `hk-chip--violet`. Une seule équivalence par carte.
- Le prix utilise `hk-price` (famille `display`, 28 px) ; le prix de référence est barré en `ink-soft`.
- Ajoute toujours « Pourquoi ce choix ? » : il ouvre la fiche de confiance (`TrustSheet`).
- Les exemples du preview (Atelier Cordon, Friperie du Marché, Cordonnerie Lemaire) sont fictifs.

À ne pas faire : plus de trois Hooks, un classement par note ou par étoiles, un chiffre d'impact sans source disponible.
